# SelfJournal first release: plan roadmap

**Spec:** `docs/superpowers/specs/2026-11-11-selfjournal-app-design.md`

The first release is split into plans that each produce working, testable software on top of the previous one. Only Plan 1 is written in full. Each later plan is written when the one before it lands, against the real interfaces in the code. The order follows spec §11a: riskiest foundations first, Canvas last.

| # | Plan | Delivers | Spec |
|---|------|----------|------|
| 1 ✅ | **Foundation** (`2026-11-12-plan-01-foundation.md`). Done 2026-11-12; outcome in `2026-11-12-plan-01-outcome.md` | Expo app with dev build, encrypted SQLite + migrations, Keystore DB key, Auto Backup off, plugin registry + event bus + on/off state, tab shell showing only enabled plugins, Plugins screen, design tokens, app lock (PIN/biometric, first-run offer, forgot-PIN via device credential), CLAUDE.md, CONTRIBUTING | §3, §4, §5, §11.1 |
| 2 ✅ | Journal: data + Cards. Done 2026-11-12; outcome in `2026-11-12-plan-02-outcome.md` (**first:** plugin context API, i.e. per-plugin settings prefix, host-owned bus subscriptions, and how to add a tab; see `2026-11-12-plan-01-outcome.md`) | Days, entries, entry-type registry (form schema + template id), the 8 built-in entry types, Cards view, detail/edit view, photo attach, encrypted media store, daily journal reminder (generic text), `journal.entryCreated` event | §6.1, §6.2 (cards half), §6.5, §11.4 |
| 3 | Habits | Habit CRUD, frequencies (daily / N per week / weekdays), mark/unmark incl. past days, weekly progress + calendar, reminders, "log the fruits" → Habit win entry, `habit.completed` | §7 |
| 4 | Recovery | Tracked behaviours, start date, wins (money, time, clean days), slip logging with one-day deduction, slip-reflection offer, Recovery note, "Need support?" helplines, `recovery.cleanDay` / `recovery.slip` | §8 |
| 5 | Gamification | Award ledger, XP rules contributed by plugins, at-most-once awards, level curve, achievements (tiers, hidden, history-checked), unlock moment, trophy case, achievement stickers exposed to Journal | §9 |
| 6 | Life stats | 3–6 stats (default 5, renameable), ranks 1–5 from 1, action→stat mapping UI, daily decay with catch-up and floor, radar chart on Me. **Checkpoint: numbers reviewed with user.** | §10 |
| 7 | Canvas + frames | Vertical canvas per day, linked vs day items, frames as windows (cropped view), move/rotate/resize/layer, doodles, GIFs, tape, sticker tray, templates with auto-arrange + random variation, Cards⇄Canvas toggle | §6.2–6.4, §6.6–6.8 |
| 8 | Backup, updates, release | Encrypted password-protected export/restore, GitHub releases update check, signed APK release pipeline to GitHub releases, "delete this plugin's data" action on the Plugins screen | §4.3, §11.2, §11.3 |

Plans 3 and 4 can run in either order. Plans 5 and 6 need 3 and 4 to emit events (they can be built first against fake events, but are more useful after).
