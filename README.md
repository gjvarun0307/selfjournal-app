# SelfJournal

A local-only, encrypted, plugin-based self-help and journaling app for Android (Expo / React Native). Your data never leaves your device: no accounts, no backend, no analytics.

Status: early development. Plan 1 (foundation) complete. See [CONTRIBUTING.md](CONTRIBUTING.md) to write a plugin and the [design spec](docs/superpowers/specs/2026-11-11-selfjournal-app-design.md) for the full picture.
